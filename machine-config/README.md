# machine-config

Backups of this machine's factory calibration, copied from the laser PC (see `lightburn.md`):

- `markcfg7` (or `markcfg0`): the EzCad2 config from its `plug\` folder. LightBurn imports it.
- `*.cor`: lens correction table, if the EzCad2 folder has one.

Nothing here yet. These files are binary or tool-owned: never hand-edit them.
